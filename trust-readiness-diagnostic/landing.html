The Framework

10 Control Dimensions

Every dimension maps directly to what external counterparties evaluate during technical due diligence.

D1
Authorization Scope
What is the agent explicitly permitted to do, and what constrains it?
D2
Audit Provenance
Can every agent action be traced, timestamped, and attributed?
D3
Human Override
Can a human halt, redirect, or reverse agent actions in real time?
D4
Blast-Radius Containment
What is the maximum damage a single agent error or breach can cause?
D5
Data Sovereignty
Where does sensitive data flow, and who governs it?
D6
Failure Mode Handling
Does the system degrade gracefully or cascade unpredictably?
D7
Model Transparency
Is the underlying model documented, version-locked, and change-managed?
D8
Third-Party Dependency Risk
What happens if an API, model provider, or tool fails?
D9
Compliance Alignment
Does the workflow align with applicable regulatory frameworks and standards?
D10
Incident Response Readiness
If the agent causes harm, is there a clear response, notification, and remediation path?
